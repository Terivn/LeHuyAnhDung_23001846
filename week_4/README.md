# Week 4 - Quan ly Gio hang (PHP + MySQL)

## Cau truc
```
week_4/
  database.sql
  app/
    common/dbConnect.php
    model/product.php
    view/header.php
    view/footer.php
    assets/style.css
    index.php
    product_list.php
    product_add.php
    product_edit.php
    product_delete.php
```

## Cach chay
1. Copy thu muc `app/` vao `htdocs` (XAMPP), vi du: `htdocs/shop/`.
2. Import `week_4/database.sql` vao phpMyAdmin (tao DB `shopping_cart`, bang `products`, 5 san pham mau).
3. Neu MySQL khac user/pass root/rong, sua trong `app/common/dbConnect.php`.
4. Mo trinh duyet: `http://localhost/shop/product_list.php`.
